# Упражнения — строго в этом порядке

1. `flash` — карточки на первые 5 слов: `{ "type": "flash", "cards": [пять значений w] }`.
2. `match` — «Соедини пары», 5–6 устойчивых сочетаний с этими или прошлыми словами: `{ "type": "match", "title": "Соедини пары", "pairs": [[левая часть, её перевод, правая часть, её перевод], ...] }`. Каждая левая часть должна подходить только к своей правой — без двусмысленности.
3. `cloze`, `mode: "select"` — связный текст по теме дня (80–130 слов, 5–8 пропусков). Пропуски `{0}`, `{1}`… идут по порядку, каждый встречается ровно один раз. В каждом пропуске `a` — правильный ответ, `o` — 3 варианта (правильный и два правдоподобных из слов дня или прошлых дней, той же части речи и формы, с той же заглавной буквой), `why` — по-русски: почему здесь именно это слово, а не другой вариант. Неправильные варианты должны давать грамматически возможное, но неверное по смыслу предложение — чтобы выбирать приходилось по значению.
4. `odd` — «Найди лишнее», 3 ряда по 4 слова: `{ "w": [4 слова], "o": индекс лишнего 0–3, "why": "..." }`. Лишнее слово ставь на разные позиции. **Все 4 слова в ряду — одной части речи и одного типа** (четыре вещи, четыре ткани, четыре прилагательных про силуэт), а лишнее отличается по смыслу: одежда/обувь, натуральное/синтетика, свободное/облегающее, нейтральное/оценочное, 1920-е/1970-е и т. п. Ряд, где лишнее угадывается по части речи или по тому, что это «не про одежду вообще», — слишком лёгкий.
5. `flash` — карточки на оставшиеся 5 слов.
6. `cloze`, `mode: "type"`, `"title": "Complete the sentences"` — 5 пронумерованных предложений, разделённых `\n`, в каждом один пропуск. Ученица вводит слово сама, вариантов нет. `alt` — другие верные написания или синонимы, которые тоже засчитываются.
7–8. Два грамматических упражнения: {{grammarTypes}}. Поле `g` — `"{{gid}}"`.

Всего 8 упражнений: 6 на лексику и 2 на грамматику. Ещё одно упражнение на повторение приложение добавит само.

## Грамматические упражнения

`tense` — смена времени по маркеру:
```
{ "type": "tense", "g": "{{gid}}", "tenses": [2–3 времени на выбор],
  "bases": [ 2 базы, каждая:
    { "base": "исходное предложение в Present Simple со словом дня",
      "tr": [3 трансформации, каждая:
        { "m": "маркер времени", "tpl": "предложение, где маркер встречается дословно, а на месте сказуемого стоит {}", "a": ["верная форма сказуемого", "вариант с сокращением, если возможен"], "t": "время из tenses", "why": "по-русски: почему маркер требует это время" } ] } ] }
```

`spot` — найди ошибку:
```
{ "type": "spot", "g": "{{gid}}", "sets": [ 2 набора, каждый:
  { "sentences": [3 предложения со словами дня — ровно в одном типичная ошибка, два других полностью правильные],
    "err": { "s": индекс предложения с ошибкой 0–2, "span": "неверные слова точно как в предложении, целыми словами, без знаков препинания", "fix": ["исправление", "другой верный вариант"], "g": "{{gid}} или id прошлого правила", "note": "по-русски: где ошибка и почему так нельзя" } } ] }
```
Ошибки типичные для русскоговорящих: время, -s в третьем лице, предлог, форма глагола, герундий/инфинитив — то, что проходит правило дня. Один набор может проверять правило из прошлых дней. `span` должен как можно точнее накрывать ошибку (1–3 слова).

`builder` — собери предложение по формуле:
```
{ "type": "builder", "g": "{{gid}}", "items": [ 2–3 пункта, каждый:
  { "ctx": "по-русски: ситуация",
    "formula": ["элементы", "грамматической", "формулы"],
    "parts": ["готовый текст", { "v": "ГЛАГОЛ КАПСОМ", "a": ["верная форма"], "f": [индексы элементов formula, к которым относится слот], "rule": "по-русски: какое правило, если ошиблась" }, "готовый текст", { "p": [3 предлога или служебных слова], "a": "верный", "f": [индекс], "rule": "..." }, "окончание."] } ] }
```
В каждом пункте 1–2 слота: один на форму глагола (`v`) и, если уместно, один на выбор предлога или служебного слова (`p`). Предложение целиком — части, склеенные через пробел, — должно быть грамматически правильным. Последней частью всегда идёт текст с точкой («the 1920s.»), а не слот: точка или запятая отдельной частью покажется с пробелом перед ней. Если слот естественно стоит в конце, перестрой предложение.

# Требования к качеству

- Пиши на британском английском (colour, trainers, catalogue), как в остальном курсе.
- Факты по истории моды должны быть точными. Если не уверен в дате или имени, пиши обобщённо — не выдумывай.
- Все пояснения (`why`, `note`, `rule`, `ctx`, переводы) — по-русски, коротко, 1–2 предложения, на «ты»-нейтральном тоне без восклицаний.
- Тексты и предложения связаны с темой дня и с работой стилиста, а не абстрактные.
- Каждый ответ однозначен: если подходит и другое слово, добавь его в `alt` или переделай предложение.
- Подставь каждый правильный ответ в его пропуск и перечитай предложение целиком: оно должно быть грамматически правильным (число, артикль, форма слова). Не ставь перед пропуском a/an — артикль выдаёт ответ; перестрой предложение.
- Грамматика в упражнениях на лексику — не сложнее правила дня и уже пройденных правил.
