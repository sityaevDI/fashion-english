# Fashion English — английский для стилиста

## Как открыть
Открой ссылку **https://sityaevdi.github.io/fashion-english/** в Chrome или Safari на компьютере и добавь её в закладки.

Ничего устанавливать не нужно, аккаунты и ИИ не нужны. Новые тренировки появляются по той же ссылке — просто обнови страницу.

## Что внутри
- **Тест уровня** — 20 вопросов, около 10 минут. Его можно перепройти в конце курса и сравнить.
- **Тренировки** — программа на 90 дней: основы, потом десятилетия с 1920-х по 2000-е, в конце работа стилиста. Каждый 5-й день — «на съёмке»: брифы, бюджеты, кампании.
- **База знаний** — все слова (с переводом, определением, примером и произношением) и грамматические правила.
- **Профиль** — прогресс, серия дней, слова на повторении, уровень.

В одной тренировке 8–9 упражнений: 6–7 на слова и 2 на грамматику. Слова, в которых была ошибка, возвращаются в следующих тренировках.

## Важно про прогресс
Прогресс хранится в браузере на этом компьютере. Обновления сайта его не стирают, но если почистить данные сайтов или открыть ссылку в другом браузере, прогресса там не будет. В профиле есть кнопка «Сохранить прогресс в файл» — нажимай её иногда.

## Сейчас готово
Тренировки 1–5 (блок «Основы»). Остальные в плане помечены «скоро».

## Что проверить в первых пяти тренировках
1. Уровень: слишком легко, нормально или слишком трудно?
2. Время: укладывается ли тренировка в 20 минут?
3. Слова: правильные ли переводы и подходят ли они для работы стилиста?
4. Упражнения: какой тип нравится, какой раздражает?
5. Что-то сломалось или неудобно — что именно и в каком упражнении.

### Для того, кто будет дописывать
- `data/program.js` — план на 90 дней (названия, грамматика по дням).
- `data/blockNN.js` — слова и упражнения блока. Новый блок = новый файл + строка `<script>` в `index.html`.
- `data/grammar.js` — правила, `data/placement.js` — тест уровня.
- `app.js`, `app.css` — движок и оформление.
- Публикация: push в `main`, GitHub Pages обновится за минуту. После изменений подними `?v=N` у файлов в `index.html`, иначе браузер до 10 минут держит старые версии.

#### Генерация блоков через Gemini (`tools/`)
Нужен Node.js 18+. Ключ положи в `tools/.env` строкой `GEMINI_API_KEY=...` (файл в `.gitignore`) или задай переменной окружения.

```
node tools/generate.js --list-models     # какие модели доступны по ключу
node tools/generate.js --block 2         # правила грамматики блока + дни 11–20
node tools/generate.js --days 11-13      # только эти дни
node tools/generate.js --days 12 --force # перегенерировать день заново
node tools/validate.js                   # проверить все данные сайта
```

- Генератор пишет `data/blockNN.js`, расписывает недостающие правила в `data/grammar.js`, добавляет `<script>` в `index.html` и поднимает `?v=N`. Коммитить нужно самому, после того как пройдёшь новые дни в браузере.
- Каждый ответ модели проверяется (`tools/lib.js` → `checkDay`): ответ есть среди вариантов, ошибка в Error Spotting находится в предложении, слова не повторяют прошлые дни, упражнений не больше 9 и т. д. Если что-то не так, ошибки уходят обратно модели, до трёх попыток.
- Проверка ловит поломки, но не ошибки по смыслу: переводы, факты и однозначность ответов всё равно смотри глазами.
- Уже записанные дни генератор берёт из `data/blockNN.js`, поэтому их можно править руками. Перегенерировать день — `--force`.
- Промпты лежат в `tools/prompts/`, учебные тексты и словарь из ТЗ — в `tools/sources/` (какие тексты к какому блоку — `SOURCES` в `generate.js`).
